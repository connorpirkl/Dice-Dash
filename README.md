Dice Dash

Description

Dice Dash is a simple dice-based board game written in Python. The player starts at the beginning of the board and tries to reach the finish line by rolling a die and moving forward.

The player has a limited number of turns to reach the end of the board. Each turn, the player can choose to roll the die or quit the game.

Features

Roll a virtual die.

Move across the game board.

Display the player's current position.

Keep track of remaining turns.

Win by reaching the end of the board.

Quit the game at any time.

How to Play

Run the Python program.

The game board will be displayed.

Press y to roll the die.

Your player will move based on the dice roll.

Continue rolling until you reach the finish line or run out of turns.

Press n if you want to quit the game.

Requirements

Python 3

No additional libraries are required.

How to Run

Download or clone this repository.

Open the project in your Python editor.

Run the main Python file.

Follow the instructions displayed in the console.
